# THE WEBSITE IN PROGRESS

A voice-first experimental website builder: the website is also the editor.

## What it does

- Voice commands with the browser Web Speech API
- Natural-language local command engine
- Add headings, text, buttons, cards, circles, images and dividers
- Change colors, backgrounds, size, position and animations
- Create and switch pages
- Select and edit elements with an inspector
- Undo / redo
- Build history
- Preview mode
- HTML export
- LocalStorage persistence
- Responsive layout and reduced-motion-friendly CSS

## Try saying

- “add a red button called ENTER”
- “move it top right”
- “make it float”
- “make it blue”
- “create a page called Gallery”
- “make a website about space”
- “duplicate this”
- “delete this”
- “change the background to blue”

No API key is required for the prototype. Voice recognition support depends on the browser.

The project is intentionally a single-file static app so it can run immediately on GitHub Pages, Vercel, or any static host.
